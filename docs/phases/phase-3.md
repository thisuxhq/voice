# Phase 3 — Multi-modal + multi-agent

**Goal:** Expand beyond single-agent audio into richer real-time apps.

## Scope

| Area | Deliverable |
| ---- | ----------- |
| Media | Video support |
| Media | Avatars |
| Orchestration | Multi-agent workflows |

## Acceptance criteria

1. Video track attach/detach via transport plugins.
2. Avatar providers plug in as a rendering/TTS-adjacent surface.
3. Multi-agent handoff preserves session context and emits agent-switch events.

## Depends on

Phases 1–2 (stable session, events, tools, observability).
